### Recurring Gotchas

- (2026-10-06, levels_5_9_20261006) Test the distribution of a seeded shuffle, not only that it is stable. The option shuffle multiplied a 32-bit seed in a JavaScript number, lost the low bits, and put 99% of the answers last in 2,220 MCQs; a "same input, same output" test passed. Also: a print file in `primary/<project>/` is a build output; rebuild it after any package edit (the Quest 4 and Origins 3.2 print files missed the pre-review fixes for 3 days). Also: in a Thai regex, the leading vowels เ แ โ ใ ไ (U+0E40–0E44) start the next syllable; exclude only the marks that follow a consonant (U+0E30–0E3A, 0E45, 0E47–0E4E). A name fix that excluded all of them skipped "มียเขียน", and its count check used the same pattern and reported 0; check with a second, different pattern.
- (2026-03, consolidated) Section toggles travel as query strings: wire a new toggle through the frontend state, the URL params, and the compile route, and read it with `=== 'true'` or `!== 'false'`, never a truthy check. Next.js previews: print a Paged.js iframe with `iframeRef.current.contentWindow.print()` (`window.print()` prints the outer UI), and show `blob:` URLs with a plain `<img>`, not `next/image`. (2026-03-22, consolidated) Playwright: strict mode matches more than you expect (a label and its section header, a `CardTitle` div, a Paged.js section split across pages): prefer `getByLabel` and `.first()`. Paged.js is slow (45–60 s for 14+ lessons): `test.setTimeout(90000)`, ≥60 s locators at the document end. A `fixed inset-0` modal blocks clicks underneath; use `page.frameLocator('iframe')`, not `.contentFrame()`.
- (2026-03, consolidated) Paged.js small rules: use `break-before: right` (or `break-after: page` on the element before) to push a section to a new page; keep `@page` rules only in the document wrapper, not in single templates; draw tracing text in light gray (`#e0e0e0`) with a sans-serif fallback. A heading at the foot of a page: put the heading, its intro, and its list in one `break-inside: avoid` block (the teacher manual ignored `break-before: page` on nested parts, 2026-10-20). (2026-10-20, teacher_manual_app_20261020) A heading stays with its first block only inside one `break-inside: avoid` wrapper; Paged.js ignored `break-after: avoid` and a nested `break-before: page`. Look at every page of a full-book build on contact sheets: fixture tests missed 3 defects in the Origins 3.1 manual, one from HTML that the lesson data stores (`vocab_fill` blank span). (2026-10-22, storytime_week_package_20261022) Put page-break CSS in the `<head>`: a `<style>` in the body colored the page but Paged.js ignored its `break-before: page`. The Thai manual CSS sets `word-break: break-word`, which splits large Latin title words ("STORYTIM/E"); give such a heading `word-break: keep-all`.
- (2026-04-26, primary_compile_layout_papercuts; merged 2026-11-07) Primary Step 11 Guided Writing is height-sensitive in print. To keep the section title and writing box together, trim the primary template vertically first: reduce padding, planner line count, draft line count, and QR block size before reaching for harder page-break rules. For primary Step 3 article pages, avoid using `overflow:auto` as a clearfix around floated article imagery in printable containers. In Paged.js it can interact badly with fragmentation and clip images at page boundaries. Use a clearfix pseudo-element instead, and if the QR intro keeps orphaning the section title, start the article step on a fresh page in print. (2026-04-26, primary_pipeline_bugs) Imported Primary lessons can hold legacy `article_image_url` arrays: the renderer tolerates them, but the schema-backed edit and save paths need a string `article_image_url` and positioned `article_images`; canonicalize imported lessons before validation. (2026-04-26, thai_vocab_backfill_origins_a0) Bilingual support in this workbook stack is split: `vocabulary[].thai_definition` already feeds glossary/flashcards/teacher guide, but student lesson pages need explicit template rendering and worksheet matching needs its own `vocab_match[].thai_definition` if you want Thai to survive schema-backed editing instead of being baked into English strings.
- (2026-08-03, teacher_guide_renumbering) Step numbers are the **student workbook's**, not the app's. The manual carried a 14-step teacher sequence against a 13-step printed workbook for months. The app build still labels those screens 9–14, so any doc that renumbers must keep an explicit numbering note and leave `app step N.png` filenames on the app's scheme while `WB N` files follow the workbook's — otherwise the next editor "fixes" the mismatch back. (2026-08-03, teacher_manual_generation_20260426) Paged.js 0.4.3 paginates through a requestAnimationFrame callback chain (next frame scheduled only from the previous task's completion), so one dropped rAF — background tab, CPU contention, or a visible-but-occluded tab whose compositor delivers no frames while `visibilityState` stays "visible" — silently freezes the render at a low page count with an idle main thread. The rAF shim must never rely on visibility alone: arm every tick with both a native rAF and a setTimeout(0) fallback (first to fire wins, cancel the other) so progress is independent of frame delivery, and flush the hidden queue on visibilitychange. Also avoid `overflow:hidden` on fixed-height full-page elements (nondeterministic freezes).
- (2026-10-07, book_covers_20261007) Canva SVG exports draw text as outlines and keep no font names. Find the font by pixel overlap: render each candidate at the Canva glyph origins and search weight and size (title: League Spartan 700, 0.89; Thai: Noto Sans Thai, Canva's fallback, 0.95). One font size with `size-adjust` on the Thai face gives both Canva sizes. Canva also places art per page by hand: read the placement from the SVG, not from one page. Chrome breaks Thai inside compound words ("งาน / อดิเรก"), and `word-break: keep-all` has no effect on Thai. Put each run between spaces in a `white-space: nowrap` span (a `|` in the data adds a break point), and fail the render when a run is wider than its box. Chrome rounds font metrics to whole pixels, so measure the first baseline in the page and move the box, not a computed offset.
### Patterns That Worked Well

- (2026-10-21, teacher_manual_app_20261020) Translated Thai for print: a term count and a CJK sweep are not a Thai check. One independent proofread subagent (all Thai sources plus the app's `th.json`, read-only, findings with file:line, current text, proposed text, severity) found 3 High errors (a wrong fact, "โครงการ" for lesson, a reversed instruction) and many word-for-word lines. Check each finding against the code before you apply it: the guide importer reads the prefix "ขั้นตอนที่", so one valid style finding had to stay out. (2026-10-22, storytime_week_package_20261022) The same holds for English content: one independent review subagent per Storytime week found 6 to 10 real defects each time (pages over the word limit, a wrong claim about a sound, a hint picture in the colour of another object, a family word on no page), after the gate passed.
