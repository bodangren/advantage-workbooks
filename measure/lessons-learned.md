### Architecture & Design
<!-- Decisions made that future tracks should be aware of -->

- (2026-10-01, lesson_packages_20261001) One lesson package (`content/primary/<book>/<lesson>.json`, schema `lib/lesson-package/schema.ts`) holds every part of a lesson: text, glossary, bank, print set, activities, Thai, pictures, audio, tags, approval, and database ids. For a new lesson, the print JSON in `primary/<project>/` (`scripts/build-workbook-json.ts`), the app rows (injector), `tags.json`, and the print data are outputs of it: edit the package, then build again. An old printed lesson (Origins 2, 3.1) keeps its text in `primary/`, and `meta.printed.lock` holds its hashes.

(2026-08-03, teacher_manual_generation_20260426) Paged.js 0.4.3 paginates through a requestAnimationFrame callback chain (next frame scheduled only from the previous task's completion), so one dropped rAF — background tab, CPU contention, or a visible-but-occluded tab whose compositor delivers no frames while `visibilityState` stays "visible" — silently freezes the render at a low page count with an idle main thread. The rAF shim must never rely on visibility alone: arm every tick with both a native rAF and a setTimeout(0) fallback (first to fire wins, cancel the other) so progress is independent of frame delivery, and flush the hidden queue on visibilitychange. ### Patterns That Worked Well
<!-- Approaches worth repeating -->

- (2026-10-06, levels_5_9_20261006) Parallel content writers: put the cast facts (names in use, ages, kinship, dates fixed in other books) in each writer's prompt, and give each subagent a private scratch folder. Writers reused a bible name ("Alex", a pen pal), made a blond Thai boy, and set dates that clashed across books; one agent ran another agent's script from the shared scratchpad. A separate editor pass after the writers found 168 faults that the checks cannot see (two true MCQ options, fill items with two answers, pictures that disagree with the text). Give each writer its own list of free swap words that excludes every map: Adventure 8.1 writers swapped in 4 words that the 8.2 map held, and bank-7 used November Saturdays that Adventure 8.1 trips held.
- (2026-10-21, teacher_manual_app_20261020) Translated Thai for print: a term count and a CJK sweep are not a Thai check. One independent proofread subagent (all Thai sources plus the app's `th.json`, read-only, findings with file:line, current text, proposed text, severity) found 3 High errors (a wrong fact, "โครงการ" for lesson, a reversed instruction) and many word-for-word lines. Check each finding against the code before you apply it: the guide importer reads the prefix "ขั้นตอนที่", so one valid style finding had to stay out. (2026-10-22, storytime_week_package_20261022) The same holds for English content: one independent review subagent per Storytime week found 6 to 10 real defects each time (pages over the word limit, a wrong claim about a sound, a hint picture in the colour of another object, a family word on no page), after the gate passed.
