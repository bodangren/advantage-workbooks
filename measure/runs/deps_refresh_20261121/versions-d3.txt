  the vitest types through the global jest.Matchers namespace, which vitest 5 drops.
  Upstream names the fix: @testing-library/jest-dom 8.0.0 README.md line 160 asks for
  vitest 5 or later, and README.md lines 162-168 ask for the import
  '@testing-library/jest-dom/vitest' in the setup file. dashboard/vitest.setup.ts:1 imports
  the root entry, so types/vitest.d.ts stays out of the program
  (capture green-d3-r7-vitest5-listfiles.txt). A setup file change is test code, which
  this track does not allow. All three packages went back to their 2c944316 versions.
