
Generate a song (music-3.0)
Usage: mmx music generate --prompt <text> (--lyrics <text> | --instrumental | --lyrics-optimizer) [--out <path>] [flags]

Options:
  --prompt <text>         Music style description (e.g. "cinematic orchestral, building tension"). Max 2000 chars when combined with structured flags.
  --lyrics <text>         Song lyrics with structure tags (newline separated). Supported: [Intro], [Verse], [Pre Chorus], [Chorus], [Interlude], [Bridge], [Outro], [Post Chorus], [Transition], [Break], [Hook], [Build Up], [Inst], [Solo]. Tags must be clean — no descriptions inside brackets (they will be sung). Max 3500 chars.
  --lyrics-file <path>    Read lyrics from file (use - for stdin). Same tag rules as --lyrics.
  --lyrics-optimizer      Auto-generate lyrics from prompt (cannot be used with --lyrics or --instrumental)
  --instrumental          Generate instrumental music (no vocals). music-2.6/music-2.5+: native is_instrumental flag; music-2.5: lyrics workaround. Cannot be used with --lyrics.
  --vocals <text>         Vocal style, e.g. "warm male baritone", "bright female soprano", "duet with harmonies"
  --genre <text>          Music genre, e.g. folk, pop, jazz, electronic
  --mood <text>           Mood or emotion, e.g. warm, melancholic, uplifting
  --instruments <text>    Instruments to feature, e.g. "acoustic guitar, piano, strings"
  --tempo <text>          Tempo description, e.g. fast, slow, moderate
  --bpm <number>          Exact tempo in beats per minute
  --key <text>            Musical key, e.g. C major, A minor, G sharp
  --avoid <text>          Elements to avoid in the generated music
  --use-case <text>       Use case context, e.g. "background music for video", "theme song"
  --structure <text>      Song structure, e.g. "verse-chorus-verse-bridge-chorus"
  --references <text>     Reference tracks or artists, e.g. "similar to Ed Sheeran"
  --extra <text>          Additional fine-grained requirements not covered above
  --model <model>         Model: music-3.0 (default), music-2.6, music-2.6-free, music-2.5+, or music-2.5.
  --output-format <fmt>   Return format: hex (default, saved to file) or url (24h expiry, download promptly). When --stream, only hex.
  --aigc-watermark        Embed AI-generated content watermark in audio for content provenance
  --format <fmt>          Audio format: mp3, wav, pcm (default: mp3)
  --sample-rate <hz>      Sample rate (default: 44100)
  --bitrate <bps>         Bitrate (default: 256000)
  --stream                Stream raw audio to stdout
  --out <path>            Save audio to file (uses hex decoding)

Examples:
  mmx music generate --prompt "Upbeat pop" --lyrics "La la la..." --out summer.mp3
  mmx music generate --prompt "Indie folk, melancholic" --lyrics-file song.txt --out my_song.mp3
  # Auto-generate lyrics from prompt:
  mmx music generate --prompt "Upbeat pop about summer" --lyrics-optimizer --out summer.mp3
  # Instrumental:
  mmx music generate --prompt "Cinematic orchestral, building tension" --instrumental --out bgm.mp3
  # URL output (24h expiry — download promptly):
  mmx music generate --prompt "Upbeat pop" --lyrics "La la la..." --output-format url
  # Instrumental with music-3.0:
  mmx music generate --prompt "Cinematic orchestral" --model "music-3.0" --instrumental --out bgm.mp3
  # Detailed prompt with vocal characteristics:
  mmx music generate --prompt "Warm morning folk" --vocals "male and female duet, harmonies in chorus" --instruments "acoustic guitar, piano" --bpm 95 --lyrics-file song.txt --out duet.mp3

API Reference: https://platform.minimaxi.com/docs/api-reference/music-generation

Global flags (--api-key, --output, --quiet, etc.) are always available.
Run mmx --help for the full list.
