## How to read the table

- One row is one changed item. The column "field" is the JSON path in `content/storytime/l2/w<nn>.json`. The numbers in a path are 0-based array indexes of HEAD `ddc70618`.
- A path with `{en,th}` names two parallel lines: the English line under `en` and the Thai line with the same index under `th`. The row changes both lines.
- A path that ends in a BiText (`focus.paSkill`, `opening.pa.<i>`, `harder`) changes its `en` and `th` keys.
- A value in backticks is the exact string or the exact JSON value. Quotation marks inside a string are part of the string. A backslash before a bar is not part of the value.
- `(delete the item)` removes the array item. Green removes the items of one array from the highest index to the lowest index, after all the value changes of the week.
- `(append)` adds a new last item to the array, after the deletions. The text after `(append) ` is the item.
- `(none)` and `(no item)` mean that the key or the item does not exist at HEAD.
- A row with `-` in both Thai columns holds data with no Thai: the old value and the new value stand in the English columns.
- The key order of a new object follows the row: `focus.paStage` goes after `focus.paSkill`. A new benchmark item keeps the key order `kind`, `sound`, `pictures`, `answer` (rows 1 to 4 have this order), with no `position` key (the default is `first`).
