# Track: Localization & Thai-Market Teacher Support

## Overview

The workbooks are sold into Thai private and public schools as part of a blended English-learning program. Many Thai teachers who administer the workbooks are non-native English speakers who may struggle to deliver the activity instructions fluently or explain the pedagogical intent to students in English.

This track adds two localization features:

1. **Bilingual Activity Instructions** — Every activity section in the compiled workbook (vocabulary list, comprehension questions, vocab-match, vocab-fill, sentence order, writing prompt, crossword, word search) gains a Thai-language instruction line printed below the English instruction. This helps students who need clarification and signals to teachers the intended task.

2. **Thai Instructional Scripts in the Teacher Guide** — The auto-generated Teacher Guide section (already implemented in the `teacher_guide_generator_20260310` archive track) is extended with a "Classroom Script" subsection per lesson. The script provides the teacher with: a suggested Thai-language opening statement, step-by-step facilitation notes in Thai for each activity, and a Thai-language debrief prompt. These are generated by Gemini and stored in the lesson JSON.

Both features are opt-in at the project level via a new `localization` field in the project metadata, so that workbooks not targeting Thai-market teachers are unaffected.

## Functional Requirements

### 1. Project-Level Localization Setting
- Add an optional `localization` field to the `ProjectMetadata` interface in `dashboard/lib/filesystem.ts`:
  ```typescript
  localization?: {
    bilingual_instructions: boolean;  // default false
    teacher_script_language: "th" | null;  // null = no script
  }
  ```
- Add UI controls for this setting in the project settings area of the dashboard (or the project creation modal). Use the existing Radix UI `Select` and checkbox-equivalent toggle pattern.
- Persist to the project's `metadata.json` file (or the Postgres `projects` table after the monorepo import, if that has landed — this track assumes filesystem persistence for independence).

### 2. Bilingual Instruction Strings
- Create `dashboard/lib/i18n/th.ts` exporting a constant `TH_INSTRUCTIONS` — a TypeScript object mapping section keys to Thai instruction strings:
  ```typescript
  export const TH_INSTRUCTIONS: Record<string, string> = {
    vocabulary: "คำศัพท์: อ่านและจำคำศัพท์แต่ละคำ",
    comprehension: "การอ่านเพื่อความเข้าใจ: เลือกคำตอบที่ถูกต้องที่สุด",
    vocab_match: "จับคู่คำศัพท์: เชื่อมคำกับความหมายที่ถูกต้อง",
    vocab_fill: "เติมคำในช่องว่าง: เลือกคำศัพท์ที่เหมาะสมเพื่อเติมให้ประโยคสมบูรณ์",
    sentence_order: "เรียงประโยค: เรียงคำให้เป็นประโยคที่ถูกต้อง",
    writing_prompt: "การเขียน: เขียนเรียงความตามคำแนะนำ",
    crossword: "ปริศนาอักษรไขว้: เติมตัวอักษรในช่องตามคำใบ้ที่ให้มา",
    word_search: "ค้นหาคำ: วงกลมคำศัพท์จากตัวอักษรในตาราง",
    match_the_image: "จับคู่ภาพและคำ: ลากเส้นเชื่อมภาพกับคำที่ตรงกัน",
  };
  ```
- These strings are authoritative (not AI-generated) and reviewed by a native Thai speaker. The file is the single source of truth for all printed Thai instruction text.
- Update all Handlebars templates for activity sections to include a `{{#if bilingualInstructions}}` block that renders a `<p class="th-instruction">{{thInstruction}}</p>` element below the English instruction heading.
- The compile pipeline injects `bilingualInstructions: true` and the correct `thInstruction` string into each section's template context when the project's `localization.bilingual_instructions` is `true`.

### 3. CSS for Thai Typography
- Add to the shared workbook CSS: `.th-instruction { font-family: "Sarabun", "Noto Sans Thai", sans-serif; font-size: 10pt; color: #555; margin-top: 2pt; margin-bottom: 6pt; }`.
- The Sarabun and Noto Sans Thai fonts are loaded via a `@import url(...)` from Google Fonts in the compiled HTML's `<head>` when `bilingualInstructions` is true. This requires an internet connection during browser-based PDF generation (Paged.js), which is already the case for QR code images.

### 4. Thai Instructional Script Generation
- Create `dashboard/lib/thai-script-generator.ts` exporting `generateThaiInstructionalScript(lesson: WorkbookLesson): Promise<ThaiInstructionalScript>`.
- `ThaiInstructionalScript` type: `{ opening: string, activity_notes: { section: string, script: string }[], debrief: string }`.
- Builds a Gemini prompt instructing it to write in natural classroom Thai (ภาษาไทยในห้องเรียน), appropriate for a Thai teacher of grade 7–12 students. The prompt includes: the lesson title, CEFR level, article summary (first paragraph), and the list of activity sections.
- Uses `GoogleGenAI` from `@google/genai` (same pattern as `ai-augmentor.ts`). Returns structured JSON using `responseMimeType: "application/json"`.
- The result is stored in the lesson JSON under a new optional field `thai_instructional_script?: ThaiInstructionalScript` added to `WorkbookLessonSchema`.

### 5. Script Generation UI
- Add a "Generate Thai Script" button to the lesson editor, visible only when the project's `localization.teacher_script_language === "th"`.
- Clicking fires a POST to a new API route `dashboard/app/api/projects/[projectId]/lessons/[lessonId]/thai-script/route.ts`.
- The route calls `generateThaiInstructionalScript`, validates the result, and saves the updated lesson JSON. Returns the generated script in the response.
- Display the script in a read-only `<pre>` block or styled card in the lesson editor below the existing pedagogical metadata fields. Show a loading spinner during generation.

### 6. Teacher Guide Template Update
- Update `dashboard/templates/teacher-guide.hbs` (the existing teacher guide Handlebars template from the `teacher_guide_generator_20260310` track) to include a "Classroom Script (สคริปต์การสอน)" subsection when `lesson.thai_instructional_script` is present.
- Render: the `opening` string, then for each `activity_note`, a numbered item showing the `section` label and `script`, then the `debrief` string.
- Style the Thai script text with `.th-instruction` CSS class (same font as the bilingual instructions).

## Non-Functional Requirements

- **Opt-in Only:** All new rendering is gated on project-level flags. Projects without `localization` set are completely unaffected.
- **Static Instruction Strings:** Bilingual activity instructions are static strings in `th.ts`, not AI-generated. This ensures consistency and avoids per-compile API calls for this feature.
- **Font Loading:** Thai font is loaded from Google Fonts only when bilingual instructions are enabled. The compile HTML already loads external resources (Paged.js CDN, QR code images), so this is an accepted dependency pattern.
- **Test Coverage:** >80% on `thai-script-generator.ts` (mock Gemini), `lib/i18n/th.ts` (trivial but ensures key completeness), and the API route handler.
- **TypeScript Strict:** Zero `tsc` errors on all new files.

## Acceptance Criteria

- [ ] A new "Localization" section in the project settings allows enabling bilingual instructions and Thai teacher script.
- [ ] Compiling a project with `bilingual_instructions: true` produces a workbook where each activity section has a Thai instruction line below the English heading.
- [ ] The Thai text renders correctly in the browser print preview using the Sarabun or Noto Sans Thai font.
- [ ] Clicking "Generate Thai Script" in the lesson editor (for a Thai-market project) calls Gemini and displays the structured Thai script in the editor within 30 seconds.
- [ ] The compiled Teacher Guide for a lesson with `thai_instructional_script` includes the "Classroom Script" subsection with opening, activity notes, and debrief in Thai.
- [ ] Compiling a project without `localization` set produces output identical to the pre-track baseline (no Thai text, no font imports).
- [ ] Unit tests for `thai-script-generator.ts` mock Gemini and assert the returned object matches `ThaiInstructionalScript` shape.
- [ ] Unit tests for the updated template-renderer assert: Thai instruction is present in output when flag is true; absent when flag is false.
- [ ] `npm run lint`, `npx tsc --noEmit`, and `npm run test:run` all pass.
- [ ] `npm run build` succeeds.

## Out of Scope

- Translation of the article text itself into Thai.
- Localization of the dashboard UI (buttons, labels) into Thai — workbook content only.
- Support for languages other than Thai in this track.
- Human-in-the-loop review workflow for AI-generated Thai scripts (content team reviews manually after generation).
- Offline font fallback packaging (Thai font requires Google Fonts CDN during PDF generation).
