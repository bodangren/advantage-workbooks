# Origins 2 (A0) — Running Record Packet (Semester 1)

**สำหรับครูใช้เท่านั้น · For teacher use only · Administered on a SEPARATE DAY from the written test**

---

## 1. Purpose

A 1:1 oral reading check on a practiced-level text. It answers three questions:

1. Can the student decode text made only of Lessons 1–8 vocabulary and patterns?
2. What kinds of errors do they make (meaning, structure, or visual)?
3. Is the student ready for Origins 3 next term?

The score is **reported separately**. It is not added to the 100-point written test.

---

## 2. Student Text Card (do not mark this copy — mark the scoring sheet)

Read only the first two paragraphs of "A Day at the Park". **100 words.**

> This is Pip. Pip is a small puppy. Pip is a happy dog. This is Lily. Lily is a girl. This is Ben. Ben is a boy. This is Mia. This is Tom. They are friends. They are at the park. The park is big. The park is green. This is a good day.
>
> Lily has a new ball. The ball is red. Pip sees the red ball. Ben sees the red ball. Everyone sees the red ball. Mia and Tom play. They play with the red ball. Pip plays too. Pip runs fast. Ben runs fast too. They are happy. This is fun. The game is fun.

Print this card at large font (18pt+) for the student. The teacher holds the scoring sheet copy.

---

## 3. Administration Steps (~3 minutes per student)

1. Seat the student at a quiet table. Other students do a quiet task (coloring page provided separately).
2. Say: "Read this story out loud for me. Start here." (point). "If you do not know a word, keep going."
   Thai: "อ่านออกเสียงเรื่องนี้ ถ้าไม่รู้คำศัพท์ ให้อ่านข้อถัดไปเลย"
3. Do NOT help during the read. No prompts, no sounding out, no wait-time pressure beyond 5 seconds (after 5 seconds on one word, tell the student the word and mark it as an error given by teacher).
4. Mark errors on your scoring sheet copy using the codes below, in real time.
5. Note fluency at the end. Thank the student. Send them back to the quiet task.

Timing: students read one by one during a class period, or during break/lunch with a rotating schedule. ~25 students ≈ 2 class periods.

---

## 4. Marking Conventions (standard Reading Record codes)

| Behavior | Mark | Example |
|----------|------|---------|
| Correct | ✓ (one per word, page of ticks) | |
| Substitution | write the heard word above the printed word | printed "puppy" → says "happy" |
| Omission | circle the omitted word | |
| Insertion | ^ mark with inserted word | |
| Teacher-told after 5s | T above the word | |
| Repetition | R under the repeated part | NOT an error |
| Self-correction | SC above the word | NOT an error |

**M / S / V error analysis** — for each error, circle which cue system failed:

- **M (Meaning):** did the error make sense? ("park" → "garden")
- **S (Structure):** did the error keep grammar? ("They are" → "He is" breaks it)
- **V (Visual):** did the error look/sound like the printed word? ("puppy" → "puppy's")

---

## 5. Scoring

```
Accuracy % = (Total words − Errors) ÷ Total words × 100
Total words = 100 (so error count = accuracy subtracted directly)
```

| Accuracy | Band | Action |
|----------|------|--------|
| 95–100% | Independent on practiced text | Ready for Origins 3 pace |
| 90–94% | Instructional — expected range | Normal progression |
| 85–89% | Developing | Small-group review of flagged patterns next term |
| Below 85% | Needs support | 1:1 re-teaching plan; re-assess in 4 weeks |

* Bands are provisional for this A0 cohort; recalibrate after the first semester's data.

### Fluency scale (circle one)

1. **Word-by-word** — reads one word at a time, long pauses
2. **Some phrasing** — 2–3 word groupings, occasional halts
3. **Phrased** — reads in phrases with expression, matches punctuation

Optional: words per minute if a timer is at hand. Do not let timing affect marking accuracy.
