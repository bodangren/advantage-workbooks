# Product Definition

## Initial Concept
Use data exports from our app to programatically develop grade 7-12 workbooks for mass printing, to be used in a blended learning (app + workbooks) program sold into schools. So the workbooks need to look as professionally produced as possible while still being quick to build and deliver to the printers.

## Target Audience
- **Primary Users:** Our internal content and production teams who generate the workbooks from app data.
- **End Users:** Grade 7-12 students in Thai programs or English Programs (EP) in Thai private and public schools.
- **Future Segment:** Primary school students (Grades 3-6).

## Core Goals
- **Professional Production:** Generate workbooks that look professionally published and are ready for mass printing.
- **Efficiency:** Automate the layout and formatting process to allow for rapid building and delivery to printers.
- **Blended Learning:** Seamlessly integrate with our existing app data to support a cohesive learning experience.

## Key Features
- **Batch Processing:** Ability to compile multiple JSON lesson files into a single, cohesive workbook volume.
- **Automated Layout:** Automatic generation of Table of Contents, Preface, headers, footers, and pagination using Paged.js.
- **Data Validation:** Strict schema validation to ensure input data meets print quality and consistency standards before compilation.
- **Scalability:** Designed to handle content for Grades 7-12 now, with architecture to support Primary Grades 3-6 in the future.
