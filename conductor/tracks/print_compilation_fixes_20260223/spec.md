# Specification: Print Compilation Fixes

## Overview

Fix three critical issues with the workbook compilation and printing system in the Next.js dashboard:
1. QR codes are not being generated
2. Print pagination is broken
3. Title page and Table of Contents are missing from compiled workbooks

## Problem Statement

The current Next.js dashboard compilation system is missing key functionality that existed in the v1-legacy browser-based compiler:

1. **QR Codes**: The legacy system automatically generates QR codes from `article_url` using the `qrcode-generator` library. The current system only passes through `qr_code_url` if manually set.

2. **Print Pagination**: The legacy system uses Paged.js with proper `@page` CSS rules for professional print output. The current system's templates lack proper print CSS and Paged.js integration.

3. **Title Page & TOC**: The legacy `compileWorkbook()` generates a complete document with:
   - Title page (series name, level, tagline)
   - Preface section
   - Table of Contents with page numbers using Paged.js's `target-counter`
   - All lessons properly structured

## Functional Requirements

### FR1: QR Code Generation
- System must automatically generate QR codes from `article_url` field for each lesson
- QR codes must be rendered as SVG data URLs
- QR code library must be installed and integrated (`qrcode-generator` or equivalent)
- If `qr_code_url` is already set (manual override), it should be preserved
- QR codes must display correctly in both preview and print output

### FR2: Print Pagination
- Compiled workbook must use Paged.js for pagination
- Print CSS must define proper page size (210mm x 285mm)
- Page numbers must appear at bottom-center of each page
- First page (title page) must have no page number
- Content must break appropriately between pages (avoid breaking inside question boxes, vocabulary tables)

### FR3: Title Page
- Compiled workbook must include a title page with:
  - Main title: "Reading Advantage"
  - Series name (from project metadata or configurable)
  - Level information
  - Tagline
  - Publisher/edition info
- Title page must break to new page after content

### FR4: Table of Contents
- TOC must list all lessons with:
  - Lesson number and title
  - Genre and article type (metadata)
  - Page number (dynamically generated by Paged.js)
- TOC must use `target-counter` for page number resolution
- TOC must break to new page after content

### FR5: Preface Section
- Preface text must be included between title page and TOC
- Preface content should be configurable per workbook level

## Non-Functional Requirements

### NFR1: Performance
- QR code generation should not significantly slow down compilation
- Large workbooks (25+ lessons) should compile in under 5 seconds

### NFR2: Compatibility
- Print output must work correctly in Chrome/Edge print dialogs
- "Background graphics" must be enabled for proper print output (document this requirement)

## Acceptance Criteria

### AC1: QR Code Generation
- [ ] Given a lesson with `article_url`, when compiled, then a QR code is generated and displayed
- [ ] Given a lesson with `qr_code_url` already set, when compiled, then the existing URL is preserved
- [ ] Given a lesson without `article_url`, when compiled, then no QR code placeholder is broken

### AC2: Print Pagination
- [ ] Given a compiled workbook, when printed via browser print dialog, then pages are properly sized
- [ ] Given a compiled workbook, when printed, then page numbers appear on each page (except first)
- [ ] Given a question box spanning a page break, when rendered, then it moves to next page instead of breaking

### AC3: Title Page
- [ ] Given a compiled workbook, when viewed, then a title page appears as the first page
- [ ] Given a compiled workbook with series "Origins" and level "3.1", when viewed, then title page shows "Origins" and "Level 3.1"

### AC4: Table of Contents
- [ ] Given a compiled workbook with 5 lessons, when viewed, then TOC lists all 5 lessons
- [ ] Given a compiled workbook, when Paged.js renders, then TOC shows correct page numbers for each lesson

## Out of Scope

- PDF export (beyond browser print-to-PDF)
- Customizable page sizes
- Multiple TOC formats
- Preface content editor (will use existing preface data)
