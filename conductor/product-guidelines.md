# Product Guidelines

## Visual Aesthetic
- **Structured and "High-Value":** The layout must move away from sparse designs. Use heavy structural elements like bordered boxes, shaded backgrounds for specific sections (Word Banks, Key Vocabulary), and distinct section dividers to create the appearance of a premium, professionally produced textbook.
- **Print Specifications:** Optimized for **210mm x 285mm** (standard Chinese printer specification).
- **Full Color:** The design should utilize a sophisticated color palette to differentiate sections and enhance student engagement.

## Editorial Voice
- **Encouraging and Direct:** Clear, student-friendly instructions with motivational "call-outs" or helpful tips tailored for Grades 7-12.
- **Scaffolded Learning:** Maintain the "Hero's Journey" thematic connection where applicable, ensuring the transition between the app and the workbook feels cohesive.

## Design Elements
- **Iconography:** Use consistent, static visual icons (e.g., Pencil for writing, Brain for comprehension) next to headers to add visual complexity and assist with navigation.
- **Typography:** Mimic professional publishing standards by using a high-quality serif font for long-form reading passages and a bold, clean sans-serif for exercise headers and instructions.
- **Density:** Maximize content density on each page to ensure the workbooks feel substantial and valuable to parents and distributors.

## Implementation Constraints
- **Data-Driven:** All visual enhancements must be implemented via the HTML/CSS template to work with the existing JSON exports (Article text, one main image, and structured exercises).
